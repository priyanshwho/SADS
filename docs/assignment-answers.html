Concerns and alternative

The function now rejects numeric strings and floats that previously could be multiplied. That is a behavior change for existing callers. The meaning of -1 must also be documented and checked by every caller.

I would first agree the input contract. If only integers are valid, I would prefer an integer parameter and strict typing at the caller, or explicit validation that throws InvalidArgumentException. This makes misuse visible instead of returning an ordinary integer sentinel.

The guard does not prevent overflow. A large integer multiplied by five can become a float, conflicting with the integer return type. I would validate the supported range and test zero, negatives, numeric strings, floats, null, and integer limits.

Backend design / Proposed relational model

6. Fundraiser listing schema

Reviewed milaap.org/crowdfunding/fundraisers and Refine Search on 27 October 2026. Cards show an image, title, percentage funded, amount raised, creator, and a fundraiser URL. Filters include cause categories, tax benefits, urgency, and donation matching.

This is a proposed schema inferred from the public interface. It is not a claim about Milaap's internal database.

TableKey fieldsPurpose

donationsid PK, fundraiser_id FK, donor_id nullable FK, amount_minor, refunded_minor, currency, status, payment_reference UNIQUE, created_atPayment ledger and anonymous donations.

Relationships and correctness

A creator has many fundraisers. A fundraiser has many donations and media records, and may belong to several categories. Store money as integer minor units with an ISO currency code. Reject non-positive goals and donation amounts. Limit refunds to the original donation amount.

Calculate amount raised from captured donations minus refunds. Failed or pending payments do not count. Percentage funded is raised divided by goal, multiplied by 100. Permit overfunding in the stored value; the progress-bar width can be capped separately.

The browser displayed dollar amounts during this session. Currency display may differ from a campaign's settlement currency. Conversion needs an explicit exchange-rate source and timestamp. Never add mixed currencies directly.

Listing performance

Index published status and publication date with id as a tie-breaker. Use category join indexes and keyset pagination. A listing aggregate can cache raised totals if it is updated idempotently from verified payment events and reconciled with the ledger. Keep private donor information out of listing responses.
